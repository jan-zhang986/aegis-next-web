# Log Management Module

日志管理模块 - 用于查询和展示系统操作日志

## 目录结构

```
log-management/
├── LogManagementPage.tsx              # 日志管理主页面
├── LogFilterPanel.tsx                 # 日志筛选面板
├── LogTable.tsx                       # 日志表格
└── LogDetailDrawer.tsx                # 日志详情抽屉（可选）
```

## 功能特性

### 1. 日志查询
- 按操作人筛选（支持远程搜索）
- 按操作时间范围筛选（限制6个月跨度）
- 按操作范围筛选（系统/组织/项目）
- 按操作类型筛选（添加、删除、更新等）
- 按操作对象筛选（级联选择）
- 按操作名称搜索

### 2. 日志展示
- 表格形式展示日志列表
- 显示操作人、操作范围、操作对象、操作类型、操作名称、操作时间
- 支持点击操作名称跳转到相关页面（非删除操作）
- 支持按时间排序
- 分页展示

## 技术栈

- React 18
- TypeScript
- shadcn/ui
- TanStack Table (表格)
