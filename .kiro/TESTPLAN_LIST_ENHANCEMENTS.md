## 📝 使用说明

### 批量操作
1. 在列表中勾选要操作的测试计划
2. 工具栏会显示批量操作按钮
3. 点击对应操作按钮（执行/复制/移动/更多）
4. 在对话框中配置参数（如目标模块）
5. 确认执行

### 高级筛选
1. 点击工具栏的"筛选"按钮
2. 在对话框中选择筛选条件
3. 点击"应用筛选"
4. 列表会根据筛选条件更新
5. 筛选按钮会显示激活的条件数量

### 模块管理
1. 鼠标悬停在"全部测试计划"节点
2. 点击文件夹图标创建模块
3. 点击加号图标创建测试计划
4. 右键模块节点可编辑/移动/删除
